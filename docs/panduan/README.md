# Panduan Pemakaian SIMKEG

SIMKEG adalah aplikasi internal untuk mencatat kegiatan, penugasan tim, dan dinas luar kota, sekaligus membuat rekap periodik.

## Peran pengguna

| Peran | Bisa melakukan |
|---|---|
| **Admin** | Semua data. Membuat dan mengubah kegiatan, menugaskan tim, mencatat dinas luar kota, mengelola jenis kegiatan dan akun user, rekap seluruh unit. |
| **Staff** | Melihat dan memperbarui kegiatan yang timnya ia ikuti, melihat dinas luar kota terkait, membuat rekap dari data timnya. |

Staff tidak bisa melihat kegiatan tim lain. Pembatasan ini diterapkan di server, bukan hanya disembunyikan di tampilan.
